# 人际吸引的三因素：我们为什么会互相喜欢

心理学对"两个人为什么会互相吸引"给出了三个被反复验证的因素——理解它们，比"感觉对了"更有抓手，也更能理性看待一段关系开始阶段的温度。

## 一、接近性（Proximity）

我们更容易喜欢**物理/生活上离得近**的人：同桌、同楼、同事、常去的咖啡店——熟悉感本身会带来好感（让我想起"曝光效应"：见得多的人感觉更安全、更可靠）。

- 启示：异地/长期不见面会消耗吸引力，不是谁变了，而是"接近性"这个燃料在减少；想升温，先制造合理频次的"在一起"。

## 二、相似性（Similarity）

相似的态度、价值观、背景、兴趣，比"互补"更稳定地预测喜欢。因为同频的人让我们感到"被理解、被印证"——"我们的世界是一致的"。

- 启示：别只靠"他对我不错"支撑关系；长期关系的基石是**大方向上的相似**（对钱/家/未来的态度），小事互补无妨，大事趋同要紧。

## 三、互惠（Reciprocity）

我们喜欢**喜欢我们的人**。对方的欣赏、回应、在意，会让我们反过来投入更多好感。

- 启示：单方面的热情不会持久——健康关系里，好感是互相流淌的；如果长期只有一方在表达喜欢或投入，警惕"单向付出"的内耗。

## 组合起来看

- 一见钟情多是"接近性 + 外表/即时反馈"的启动；能走多远，看相似性与互惠是否跟上；
- 用三因素自问一段新关系："我们有机会常相处吗？大方向上像吗？我是被回应地喜欢，还是单方面投入？"——比反复琢磨"他到底喜不喜欢我"更有用。

## 边界

- 三因素是倾向性规律，不是感情公式；感情仍有不可解释的部分，理性框架是用来"照镜子"，不是拿来套公式审判。
