# 非暴力沟通（NVC）：表达需求而不引发冲突

非暴力沟通（Nonviolent Communication）由马歇尔·卢森堡提出，核心是**用表达需要代替指责**。恋爱中最常见的冲突，往往不是"谁做错了"，而是双方都用了指责式表达。

## 四步表达框架

1. **观察（不评判）**：说出客观事实，不加"总是/从不"这类绝对化词。
   - 错误：你从来不管我。
   - 正确：这周我们有三天没有单独聊过天。
2. **感受（不归因）**：表达自己的感受，不说"你让我生气"。
   - 正确：我感到有些孤单和被忽略。
3. **需要（不指责）**：说出感受背后的需要。
   - 正确：我需要感受到你在乎这段关系。
4. **请求（不命令）**：提出具体、可执行的请求，而非要求。
   - 正确：今晚可以一起散步二十分钟吗？

## 常见雷区

- **评判式开头**："你太自私了"——直接触发对方防御。
- **比较**："别人男朋友都……"——引发羞辱感。
- **强加责任**："都是因为你……"——让对方无法回应。
- **反问与命令**："你难道不知道吗？"——让对方闭嘴。

## 倾听同样重要

对方情绪激动时，先复述对方的观察、感受和需要（"你是不是觉得……所以才……？"），再谈自己的部分。倾听不是认输，而是让对话从对抗转向协作。

## 练习要点

- 表达前先停顿 3 秒，问自己："我要表达的是观察还是评判？"
- 把"你怎么……"换成"我需要……"。
- 请求要具体到可以执行的行动，而不是"你对我好一点"这种模糊要求。
