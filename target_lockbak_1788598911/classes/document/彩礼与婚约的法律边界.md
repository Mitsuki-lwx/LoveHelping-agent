# 彩礼与婚约的法律边界

彩礼是我国部分地区婚恋中的传统习俗，但法律给彩礼划了边界——婚姻应当是双方自愿的结合，不能以彩礼作为强制索取的手段。

## 法律要点

- **禁止借婚姻索取财物**：民法典第 1042 条明确"禁止借婚姻索取财物"。这里针对的是以婚姻为要挟、强行索要高额财物的行为；双方自愿的赠与不在此列。
- **彩礼不等于买卖婚姻**：自愿给付、数额合理的彩礼属于民间习俗范畴；但若以彩礼为条件强迫结婚，则可能触碰法律红线。

## 彩礼返还的常见情形

司法实践中，双方**未办理结婚登记**、或办理登记但**确未共同生活**、或婚前给付导致**给付方生活困难**的，可以主张返还彩礼——具体是否返还、返还多少，通常还要考虑共同生活时间、彩礼用途、是否有子女等因素，由法院根据实际情况裁判。

## 对恋爱顾问的启示

- 谈及彩礼时，提醒用户：彩礼是习俗，不是"购买对方"的交易；沟通时应说清"我们愿意给什么、为什么"，而不是"你要多少才肯嫁"；
- 若双方因彩礼发生严重分歧，建议回到"这段婚姻双方是否自愿、是否平等"的本质问题，而非在数额上争输赢。

## 常见雷区

- 以彩礼数额衡量感情深浅——把婚姻物化，往往埋下日后矛盾；
- 借彩礼逼迫对方或对方家庭，触及"借婚姻索取财物"的边界；
- 忽视彩礼返还的法定情形，把"给了就要不回来"当成唯一答案。
