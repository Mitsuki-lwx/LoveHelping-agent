# 爱情三角论：激情、亲密与承诺

心理学家 Robert Sternberg 提出：爱情由三个成分构成——激情、亲密、承诺；三种成分的不同组合，构成不同类型的关系。理解这个框架，能帮你看清"我们到底处于哪种爱、缺哪一块"。

## 三个成分

- **激情（Passion）**：情感上的强烈吸引与渴望——心跳、思念、"想靠近"；关系初期燃料，衰减最快；
- **亲密（Intimacy）**：分享、理解、信任、"很多话只想和你说"；需要经营，越养越厚；
- **承诺（Commitment）**：认定对方、决定共同走未来的意愿——短期承诺("在一起")与长期承诺("走下去")。

## 常见类型(简化)

- **喜欢（只有亲密）**：谈得来、有信任，但少激情与承诺——好朋友；
- **迷恋（只有激情）**：强烈吸引但缺乏了解与承诺——热恋期/一夜情式;
- **空洞的爱（只有承诺）**：为了责任/习惯在一起,已无激情与亲密；
- **浪漫的爱（激情+亲密）**：热烈又有话说,但没决定共同未来；
- **同伴的爱（亲密+承诺）**：温暖稳定,激情冷淡——长伴夫妻常见；
- **完整的爱（三者皆有）**：理想态,需长期经营。

## 实际用法

- 关系卡住时,先对照"哪个成分在缺失":是没了新鲜感(激情)？还是越来越没话聊(亲密)？还是双方对未来游移(承诺)?——缺什么补什么,而不是笼统地说"感情淡了"；
- 激情会自然衰减,单靠激情的关系必然进入瓶颈;**亲密与承诺是"越养越厚的",它们才决定能不能长期**；
- 恋爱阶段就刻意练习三件套:保持"一起创造新鲜"(激情)、定期深谈(亲密)、坦诚谈未来(承诺)。

## 边界

- 类型是归类工具不是标签:一段关系可以流动(从浪漫爱走向完整爱或同伴爱);
- "激情退了"不等于"不爱了"——用框架重新认识,别急着盖棺定论。
