# 让异地亲密保持鲜活

距离改变了一段关系的几何形状，但没有改变它的可能性。能在千里之外茁壮的伴侣不是运气好——他们是有意为之。

## 每天小 > 每周大

每天早上一个 90 秒的「在想你」语音，胜过一次精心策划的每周通话。频率建立存在感；制作精度不建立。

## 跨时区的共享仪式

看同一张落日照片。周日做同一道菜。睡前读同一章。微小的同步制造出「我们」的体感，即使时钟意见不同。

## 在说再见前规划下次相聚

即使是一个暂定的日期，也会让距离感觉有边。没有日期的距离最沉重。

## 经常聊未来

异地情侣容易陷入后勤。给梦想留出空间——那套公寓、那座城市、你们将共享的晨间习惯。在这种关系里，希望是一个动词。
