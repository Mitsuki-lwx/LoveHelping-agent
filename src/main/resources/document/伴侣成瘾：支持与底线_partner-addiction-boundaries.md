# 伴侣成瘾：支持与底线

当伴侣有酒精、赌博、游戏、药物或其它成瘾问题时，最折磨人的不是成瘾本身，而是**反复的循环**：承诺戒断—短暂好转—复发—隐瞒—崩溃。你会同时被两股力量撕扯：**想帮他，又不想再被拖下水**。这篇讲怎么在这两者之间找到一条不毁掉自己的路。

## 先理解成瘾是什么

成瘾是一种**慢性、易复发的状态**，不是"意志力差"或"人品坏"。它改变了大脑的奖赏系统，让"想要"压过"应该"。**这不等于当事人没有责任**——但理解这一点，能让你停止用"你为什么就不能争点气"这类无效指责。

## 一个关键陷阱：成为"共谋者"

家人最容易被卷进无意识的"协助循环"：

- 替他还赌债、还信用卡，掩盖后果；
- 帮他向单位/家人撒谎请假；
- 一次次接受"这是最后一次"的承诺，然后重新开始；
- 把全部注意力放在他身上，忘了自己。

**结果是：你承担了后果，他就没有动力改变。** 这在成瘾家庭干预里叫"赋能"（enabling）——听起来是爱，实际是让问题持续。

## 从"共谋"到"划界"：CRAFT 思路

一种被证实有效的家庭参与方法（CRAFT）强调：**不指责，不纵容，用边界促使对方求助**。

**1. 停止替对方兜后果**
钱、谎、丢掉的合同、错过的就医——让**成瘾者承担自己行为的自然后果**。这不是狠心，是唯一可能推动改变的力量。

**2. 划出清晰的底线（写下来）**
比如：
- 不在酒后与我同处一室 / 不酒后驾车接送孩子；
- 不再由我偿还赌债/毒资；
- 不改掉就触及"分居/离婚"的后果。

底线必须**具体、可执行、你真的能做到**。做不到的威胁会更快失效。

**3. 表达关心，同时坚持边界**
"我很在乎你，我希望你好。所以我不能再替你还钱，但我可以陪你去找医生。"——把"爱"和"纵容"分开。

**4. 抓住清醒期的机会**
在他状态好、愿意谈的时候，一起联系专业戒断资源（精神科、成瘾治疗机构、戒酒互助）。**主动示好时要接住，而不是趁机翻旧账。**

## 保护孩子（如果有）

如果家里有孩子，请把他们的安全放在第一位：

- 成瘾者与孩子的独处要有明确条件；
- 不让孩子成为"调解人"或"照顾者"；
- 孩子需要有人告诉他们："这不是你的错，也不是你该解决的问题。"

## 保护好你自己

这段关系里最容易消失的是"你自己"。请记住：

- **你没有义务无限期等待。** 你在乎他，不等于你必须陪他毁灭。
- **设立支持系统**：朋友、家人、成瘾者家属互助团体、心理咨询。
- **经济与安全独立**：保留独立账户、了解法律权益、准备退路。涉及暴力、酒驾、威胁，**先保护人身安全**。
- **接受"他可能不会好"这个可能性。** 改变只能来自他自己；你能做的是不让自己一起沉下去。

## 什么时候必须离开 / 求助

- 出现暴力、威胁、危及孩子安全 → **立即求助 110 / 120**，必要时联系当地妇联、社区；
- 你已出现抑郁、耗竭、自我怀疑到无法生活 → **全国统一心理援助热线 12356**（24 小时、免费）；
- 涉及成瘾治疗 → 到精神科/成瘾专科门诊就诊，不要自行"硬戒"（某些物质戒断有生命危险）。

## 一句话

支持不等于替他承担后果，爱也不等于赔上自己。**把边界划清楚、把专业帮助引进来、把自己保住**——这是你能做的最有力的两件事：既给他改变的机会，也给自己活路。

> 本文是常识整理，不构成医疗或法律意见。成瘾治疗请遵专业医嘱。
