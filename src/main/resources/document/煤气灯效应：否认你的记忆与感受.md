# 煤气灯效应：否认你的记忆与感受

**核心**：通过否认事实、质疑记忆、贬低感知，让你开始怀疑"是不是我太敏感/我记错了"，从而逐渐依赖对方的判断、失去对现实的把握。

**常见话术**：
- 否认发生过的事："我从来没说过这句话""你记错了吧"；
- 质疑你的感受："你太敏感了""你想太多了"；
- 重新定义你的情绪："你这就是无理取闹"；
- 让你为 ta 的情绪负责："都是你害我这样的"。

**识别**：当你发现自己频繁地为"自己的记忆和感受是否真实"感到困惑，并在争执后感到精疲力竭时，值得警惕。它是逐渐发生的——先是否认一件小事，再扩大到你的记忆、判断和人格。

**怎么办**：
1. **先确认自己的感受是有效的**：你感到害怕、不被尊重、被消耗——这些感受不是"想太多"；
2. **把行为记录下来**：时间、原话、你的感受，跳出"单次争吵"看模式；
3. **设定边界并表达**："我不接受被这样称呼""我需要你尊重我的记忆和感受"；
4. **求助**：向可信的朋友、家人说出来；若伴随暴力或人身威胁，联系警方或反家暴机构——沟通技巧修复不了控制型关系。

**边界**：
- 单次的"心情不好说错话"不等于煤气灯；判断看**模式**而非偶发；
- 识别风险信号是为了自我保护与知情决策，不是在关系里互相"贴标签"、审查对方；
- 煤气灯与爱情轰炸、间歇性强化是不同操控手段：煤气灯靠**否定你的感知**，爱情轰炸靠**初期过度热情**，间歇性强化靠**忽冷忽热的不确定性**。
