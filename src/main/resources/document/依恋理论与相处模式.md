# 依恋理论：理解自己与伴侣的相处模式

依恋理论（Attachment Theory）源于鲍尔比与安斯沃思的研究，描述人在亲密关系中的情感联结模式。理解依恋类型，有助于解释"为什么吵架后反应完全不同"。

## 四种依恋类型（Bartholomew 四象限）

| 类型 | 核心特征 | 常见表现 |
| --- | --- | --- |
| 安全型（Secure） | 相信自己值得被爱，也相信对方可靠 | 能表达需求，能独处，冲突后能修复 |
| 焦虑型（Anxious） | 害怕被抛弃，需要持续确认 | 消息回慢了就焦虑，反复试探，用"作"来测试在乎 |
| 回避型（Avoidant） | 害怕亲密，需要空间，压抑情感 | 冲突时沉默/消失，拒绝深入交流，觉得对方"太粘" |
| 恐惧型（Fearful） | 既渴望亲密又害怕受伤 | 忽冷忽热，靠近就推开，推开又后悔 |

## 与不同依恋类型相处

- **面对焦虑型伴侣**：回应要稳定及时，明确表达"我在乎你"；吵架时先安抚情绪再讲道理。
- **面对回避型伴侣**：给对方空间，不逼问"你到底怎么想的"；用文字而非当面质问沟通敏感话题。
- **面对恐惧型伴侣**：保持一致性，不忽冷忽热；允许对方反复，不因此惩罚对方。

## 对自身的觉察

- 依恋类型不是性格缺陷，而是早年经验形成的**适应策略**，可以随关系经验改变。
- 焦虑不是"太爱"，回避不是"不爱"——都是对安全感的特殊需求。
- 安全感的建立来自**可预测性**（说到做到）、**可得性**（需要时在场）、**回应性**（情绪被接住）。

## 改善方向

1. 焦虑型：练习自我安抚，把"他是不是不爱我了"转译为"我需要确认，但我可以等一等"。
2. 回避型：练习用一句话表达情绪（"我现在需要静一静，不是生你的气"）。
3. 双方：约定"情绪暂停"机制——情绪过载时暂停 20 分钟再谈，避免在应激状态做决定。
