# 夫妻共同财产与个人财产：分清楚，不内耗

谈钱是亲密关系里最容易被回避、也最伤感情的话题之一。先分清"哪些是共同的、哪些是个人的",很多争执就有了理性起点。

## 共同财产（民法典第 1062 条）

婚姻关系存续期间取得的下列财产，为夫妻共同财产，归夫妻共同所有：
- 工资、奖金、劳务报酬；
- 生产、经营、投资的收益；
- 知识产权的收益；
- 继承或受赠的财产（但遗嘱或赠与合同中确定只归一方的除外）；
- 其他应当归共同所有的财产。

## 个人财产（民法典第 1063 条）

- 一方的婚前财产；
- 一方因受到人身损害获得的赔偿或补偿；
- 遗嘱或赠与合同中确定只归一方的财产；
- 一方专用的生活用品；
- 其他应当归一方的财产。

## 对恋爱顾问的启示

- 婚前/婚后财产协议、大额赠与（彩礼、婚房首付）是否"只归一方"，直接影响日后归属——建议用户在**关系稳定期**就坦诚沟通财务边界，比冲突时刻再谈更体面；
- 帮用户区分"共同经营的钱"和"个人积蓄"，避免用"你的就是我的"绑架对方；
- 谈钱不是势利，是成年人对关系的尊重：把预期说在前面（谁出什么、怎么记账、大额支出如何商量），能避开大量"事后算账"的伤害。

## 常见雷区

- "婚后收入都算公家的"——部分情况下是错的（如婚前房产的租金、指定继承）；
- 用"你不上进"羞辱对方收入，而不是讨论家庭财务规划；
- 把财产争议拖到离婚时一次性爆发——那时候只剩对抗，没有协商余地。
