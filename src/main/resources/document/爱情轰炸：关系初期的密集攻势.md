# 爱情轰炸：关系初期的密集攻势

**核心**：关系初期用密集的赞美、承诺和"只有我们"的排他感迅速制造深度联结，让关系在极短时间内"热过头"。

**常见表现**：
- "从来没这样喜欢过谁""你是我遇到的最好的""只想和你在一起"式密集宣言；
- 快速推进关系、要求迅速确认"你是我的人""不许和别人来往"；
- 用过度投入换取你的愧疚与依赖（"我为你付出这么多"）。

**风险**：密集的正面轰炸往往是后续控制行为的铺垫——先建立"你欠我"的债务，再以此施压。来得太快太猛的"深爱"，和了解你之后的深爱不是一回事。

**怎么办**：
1. **留意节奏**：真正的关系需要时间建立信任，警惕"几天就认定终身"的强度；
2. **守住自己的边界与朋友圈**：不因对方的密集攻势放弃原有社交和支持系统；
3. **看长期一致性**：等热情期过去，对方是否仍然尊重你、接纳真实的你——而不是把"当初的疯狂"当索取的筹码。

**边界**：
- 热情本身不是问题，**用热情换取控制权、并在后期翻旧账施压**才是信号；判断看**模式**而非单次的甜言蜜语；
- 识别风险信号是为了自我保护与知情决策，不是在关系里互相"贴标签"、审查对方；
- 爱情轰炸与煤气灯、间歇性强化是不同操控手段：爱情轰炸靠**初期过度热情**，煤气灯靠**否定你的感知**，间歇性强化靠**忽冷忽热的不确定性**。
