# 家庭暴力的识别与求助：兴趣是你从哪里开始保护自己

家庭暴力不是"家务事"，而是违法甚至犯罪。识别它、知道求助路径，是保护自己与他人的第一步。

## 什么样的行为算家庭暴力

《反家庭暴力法》第二条定义的"家庭暴力"指家庭成员之间以殴打、捆绑、残害、限制人身自由以及经常性谩骂、恐吓等方式实施的**身体、精神等侵害行为**。要点：
- **不仅是打人**：精神暴力（长期贬低、恐吓、冷暴力到极端程度）、经济控制同样可能是家暴；
- **同居关系适用**：共同生活的人之间实施暴力，同样适用该法；
- **不限于婚姻内**：恋爱同居期间的暴力也受约束。

## 可用的求助与法律工具

1. **报警（110）**：暴力正在发生或有人身危险时，第一时间报警；
2. **人身安全保护令**：《反家庭暴力法》第 23 条，受害人可向人民法院申请人身安全保护令（禁止施暴者接触、靠近、骚扰申请人等），有效期最长 6 个月，可附强制措施；
3. **临时庇护与救助**：各地设有庇护所、12338 妇联维权热线等求助渠道；
4. **证据留存**：伤情照片、就医记录、报警回执、聊天记录、录音——为后续法律程序保留证据。

## 对恋爱顾问的启示

- 用户提到"他/她打了我/骂得很难听/不让我出门"时，**先分辨是否涉暴**，再谈关系修复——家暴场景下，"怎么沟通和好"是错误优先级的建议；
- 身体暴力、以威胁控制人身自由、以暴力逼迫发生性关系等，都是红旗，不应出现在"磨合""吵吵闹闹"的正常化叙事里；
- 情感顾问的边界：我们提供情绪支持与求助路径，不代替警方或法律专业人士判断案情。

## 常见雷区

- "他只有喝醉了才打人"——理由化暴力；
- "为了孩子忍忍"——孩子长期目睹暴力同样是伤害；
- 把精神暴力当"脾气不好"——经常性恐吓、贬低、孤立同属侵害。
