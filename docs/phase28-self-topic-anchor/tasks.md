# phase28 · 自我议题「答但锚定」（`anchored-help`）

> 状态：**待实施**。承接 ADR-61 的域内边界测量（Mitsuki 在 A/B/C 中选了 **C**）。

## 测量结论（ADR-61，只测量未改）

当前 `bounded-help` 的边界**实际落在「情感/人际/心理」域**，比对外宣称的「恋爱/关系」宽一档：

| 类别 | 现状 | 中位字数 |
|---|---|---|
| 恋爱 / 家人 / 朋友 | 答 | 447 / 890~1112 / 688 |
| 职场 / 辞职（纯事务） | 拒 + 转介 | 217 / 221 |
| 迷茫 | 答 | 606 |
| **总是讨好别人，怎么改** | **答满（无落点的通用六步方案）** | **1252** |

实际判据 = 「有人际/情绪/心理落点 → 答；纯粹事务/职业/法律/医疗 → 拒」。
差的正是**纯自我心理**那一格：**没有关系落点，却拿到长篇通用自我成长方案**。

## 决策（选 C：不拒，但必须锚定）

**判据写成**：自我议题**先答**，但**必须落到「这在你的哪段关系里最明显」**——
不允许交付**无落点的通用自我成长方案**。

⛔ 为什么**不选 B（收紧回恋爱/关系 = 拒掉自我议题）**：
「讨好型人格」「我很容易情绪化」这类问题在**恋爱受挫场景里极高频**，
拒掉它们 = 重演 ADR-53 的「无谓拒答」，正是本仓最贵的那类缺陷。

⛔ 为什么**不选 A（认账改成"情感"定位）**：KB 131 篇全是**关系视角**，
自我心理类无知识库支撑 → 会答得泛，且与"恋爱顾问"品牌不一致。
**边界可以比 KB 宽一档，但不能宽到没有 KB 可依。**

## 判据（实现前写死）

臂 A = `bounded-help`（现行默认）；臂 B = `anchored-help`（本轮新增）。
同 provider、只差措辞。

| # | 判据 | 通过线 |
|---|---|---|
| **J1** | 自我议题**不拒**（防"又变无谓拒答"） | G7 三问全部 `substantive`（≥150 字、无拒答信号） |
| **J2** | 自我议题**必须锚定** | G7 出现锚定标记的轮数 **≥ 2/3**（粗筛；必须读原文确认真的在问"哪段关系"） |
| **J3** | 通用展开**收窄** | G7 中位长度**下降**；且读原文确认**不再是"无落点的通用六步方案"** |
| **J4** | 域内基线**不得变差** | G8（恋爱核心）/ G1 / G2 的"关系维度"标记**不下降** |
| **J5** | 域外成果**不得丢** | G3 仍拒（`refusal_short 3/3`）；G4 转介仍 6/6、中位**不回升** |
| **J6** | 量具健康 | 逐臂报 **PKIX / 上游超时 / embedding 失败 / L3 拦截**；逐轮全文落盘 |

⛔ **判据纪律**（ADR-60 的教训）：**长度只能当粗筛**，J2/J3 的结论必须读原文；
不许只凭"变短了"就宣布修好。
