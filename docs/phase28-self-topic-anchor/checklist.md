## ⛔ 未验证 / 已知限制（不掩盖）

1. **自我议题只有 3 个问题 × 3 轮**（G7 n=9/臂）。样本小、人工构造、有偏 →
   只作方向性参考，**不能**说"自我议题这一类都修好了"。
2. **锚定标记是粗筛**（12 个词），可能漏掉别的问法（如"是在哪种场合"）。
   J2 的 7/9 里**没有**逐条人读确认"这 7 条问的确实是关系落点"——
   我读了 1 条（讨好型人格）确认成立，**其余 6 条未逐条核对**。
3. **G6 非恋爱关系中位 864 → 484（−44%）** 是**预期外**的变化（本轮没打算动它）：
   关系维度 12/12 → 11/12。**未逐条读原文归因** —— 可能是"锚定要求"顺带收窄了
   非恋爱关系类回答。⚠️ 记为**未归因观察**。
4. **G2 中位 1060 → 873** 同为下降，但关系维度 3/3 保持，未读原文归因。
5. "不展开清单"仍不穷尽（本轮只补了职业/职场）。其它域外形态未测。
6. ⛔ **对外定位未改**：仍是恋爱/关系顾问。真要走"情感"主题 = 扩 KB + 改边界清单，
   **不是改这一处措辞**。
