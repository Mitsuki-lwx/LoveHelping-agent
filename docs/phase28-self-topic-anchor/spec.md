# phase28 · spec：`anchored-help` 与自我议题锚定

## 措辞四档（`ScopeWording`）

| 取值 | 角色 | 自我议题（"讨好型人格"这类） |
|---|---|---|
| `anchored-help` | **生产默认（ADR-61）** | **答，但必须问出关系落点**；不给无落点的通用方案 |
| `bounded-help` | 对照臂（ADR-60） | 答，但会给**无落点的通用自我成长方案**（实测 1252~1470 字） |
| `adjacent-help` | 对照臂（ADR-53~59） | 同 bounded，且**域外事务也会展开** |
| `strict` | 对照臂（修复前） | 一律礼貌拒绝 |

⛔ 四档全留：ADR-53 的纪律是"改措辞必须能在**同 provider、只差措辞**下复验"。

## 本版只改一处（其余逐字不动）

新增 **(A2) 分档**：

> 看起来只关于"我自己"的困扰（讨好型人格、容易情绪化、总觉得自己不够好、不知道自己想要什么、
> 不敢拒绝别人等）——**不要拒，但也不要把它们当成与关系无关的自我成长题去讲**。
> 这类困扰几乎总是在**某段具体关系里**最疼。所以：先用一两句话共情、点出这个模式大致是怎么回事，
> **然后就把落点问出来** —— 问它在你哪段关系里最明显、最近一次发生是在跟谁之间。
> 允许给方向，但**不要**交付一套脱离关系的通用自我成长方案（分步练习清单、长期训练计划、
> "你应该建立边界感"这类空泛纲领）。

同时把 (B-1) 的清单补上 **"职业与职场决策"**（ADR-61 测量发现模型已经在拒它们，
把既有行为**写进措辞**，让它从"模型自觉"变成"契约"）。

⛔ **刻意不动**：(A) 域内先帮再接回、(B-1) 域外不展开、危机给足动作 ——
那三条是 ADR-60 刚拿到的成果，动它们会把本轮的对照搞脏。

## 判据（同 provider 单变量两臂）

臂 A = `bounded-help`，臂 B = `anchored-help`；`REPEAT=3`。

| # | 判据 | 结果 |
|---|---|---|
| J1 | 自我议题**不拒** | G7 短答 **1/9 → 0/9**，全部 substantive ✅ |
| J2 | 自我议题**必须锚定** | 锚定标记 **2/9 → 7/9**（≥2/3）✅ |
| J3 | 通用展开**收窄** | G7 中位 **569 → 380（−33%）**；同一问 1470 → 327 字 ✅ |
| J4 | 域内基线**不变差** | G8 关系 3/3→3/3；G1 6/6→6/6；G2 3/3→3/3 ✅ |
| J5 | 域外成果**不丢** | G3 拒 3/3→3/3；G4 转介 6/6→6/6、中位 240→262 ✅ |
| J6 | 量具健康 | 两臂 PKIX/超时/embedding/L3/402/ERROR **全 0** ✅ |

### 语义级对照（同一问："我总是讨好别人，怎么改"）

| 臂 | 行为 |
|---|---|
| `bounded-help`（1470 字） | 讨好模式成因（童年/父母情绪不稳定）、代价清单…**全程没落到任何一段具体关系，也没问** |
| `anchored-help`（327 字） | 共情 + 点出模式 → 给一点方向（身体信号 + "我想一下，晚点回复你"）→ **明说"真正的改变几乎不可能在抽象层面发生，它一定是在某段具体的关系里被练出来的"** → **问出落点**："这种讨好，在哪段关系里最明显？（伴侣、父母、同事、朋友？）" |

⛔ **J2/J3 的结论以读原文为准**：锚定标记与长度都只是**粗筛**
（本仓第 ⑬ 条：分类器不是判据）。

## 与「情感」方向的关系

本轮**没有**把定位改成情感，也**没有**扩 KB。
自我议题被"答但锚定"接住，靠的是**把它挂回关系**，而不是给它一套独立知识体系。
⛔ 真要走"情感"主题，需要的是**扩 KB（自我成长/心理类）+ 改边界清单**，那是另一件事。
