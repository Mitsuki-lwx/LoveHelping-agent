# spec.md — 沙盘模拟 Phase 4 设计规格

> **问题**：用户不会"练沟通"——真人练习社交成本高（尴尬/伤感情），传统文字建议太抽象记不住，缺乏真实对话的即时反馈。
>
> **方案**：AI 实时扮演目标对象，用户在模拟对话中练话术，练习结束后给出结构化复盘。

---

## 能力清单

| ID | 能力 | 说明 |
|----|------|------|
| CAP-1 | 创建沙盘会话 | 用户选择通道（真人/二次元）、输入人格参数（原型标签+说话风格+关系阶段），返回会话 |
| CAP-2 | 沙盘对话 | 用户输入消息，AI 扮演目标对象回复（基于人格参数+对话历史） |
| CAP-3 | 会话管理 | 启动/继续/重置/删除沙盘会话；30分钟无操作自动过期 |
| CAP-4 | 双通道 | REALISTIC（真人模拟）、ANIME（二次元预设，含原创角色库） |
| CAP-5 | 人设漂移检测 | 每轮异步检测角色一致性，连续3轮漂移需用户确认才重置 |
| CAP-6 | 未成年保护 | 使用时长提醒（ADR-12） |
| CAP-7 | 角色库管理 | 原型标签（傲娇/天然呆/三无/元气）+ 自创名 + AI生成头像（带标识） |

## 目标用户

有伴侣/暧昧对象的 C 端用户，希望在"不伤人"的场景下练习沟通（如：准备摊牌、如何开口提分手、如何道歉）。

## 设计骨架

```
用户入口
    │
    ▼
沙盘创建（ChatEntry /chat/sandbox/create）
    │  填写参数 → 调 agentframework 创建沙盘会话
    ▼
沙盘对话（/chat/sandbox/chat）
    │  ReactAgent 扮演目标对象（system prompt 注入人格参数）
    │  每轮 history_version 控制并发冲突
    ▼
复盘（/chat/sandbox/review）
    │  用户上传过往真实对话/对方回复 → LLM 对比分析
    │  输出：差异点、可改进点、自信心评分
    ▼
注销/过期清理（ADR-5 + ADR-12 未成年人保护）
```

**核心差异**：普通聊天是"问AI怎么办"，沙盘是"跟AI练"。

## 工具与 RAG

沙盘对话共享全部工具（含 RAG 检索 + 外部搜索），由人格参数约束使用场景：
- **RAG 知识库**：始终可用（AI 需要了解目标对象背景、历史对话）
- **外部搜索**：可用（查天气、找餐厅——沙盘场景经常涉及"去哪里约会"）
- **文件生成**：受限（目标对象不会给用户生成 PDF，但可调用知识库检索）
- 工具选择由 `persona.traits_json` 约束（如：角色是"温柔型"不会用"搜索"，而是给出温和建议）

## 人格一致性（ADR-9，a+b 方案）

| 层 | 机制 | 说明 |
|----|------|------|
| 约束层 | system prompt + structured人设 | AI 扮演目标对象，强制使用目标对象的说话方式，不跳出角色 |
| 校验层 | 每轮轻量分类器检测漂移 | 一旦回复偏离设定风格（如：忘说语气词/突然变专业），静默修正 |
| 干预层 | 连续3轮漂移 → 用户确认重置 | 不静默清空（已否决旧方案） |

## 版权安全（ADR-12）

- 角色库全部原创：原型标签+自创名+AI头像
- 三条硬规则：
  1. AI 头像加"AI 生成"标识
  2. 护栏拦截"扮演 XX（知名角色名）"，转引导至相近原创原型
  3. 未成年人防沉迷 + 使用时长提醒

## Out of Scope

- 实时语音沙盘（Phase 4+ 远期）
- 沙盘内容导出为视频/PDF（远期）
- 诊断报告回填（ADR-10 定稿后）
- relationship_profile 深度整合（沙盘诊断数据回填后自然落地）
