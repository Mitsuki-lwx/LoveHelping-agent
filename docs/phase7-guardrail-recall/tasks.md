# 护栏口语化危机加召回（Jev 第二信号）—— 任务拆分（tasks）

> 立档 2026-09-20。用户已同意。上游证据：`docs/phase7-jev-routing/spec.md` §S4
> （探针实测 Jev 对 5 例口语化自伤表达 **5/5 命中、21 例负向 0 误报**）。

## 1. 现状与缺口

`GuardrailAdvisor` 的判定来自 `GuardrailRuleService.check()`（**词典规则，零 LLM**）：

| 规则层结果 | 现在的行为 |
| --- | --- |
| `level >= 3` 且 `ruleId=self_harm` | 硬阻断，返回 `REFERRAL_TEXT`（含全国心理援助热线 400-161-9995 / 010-82951332） |
| `level >= 3` 其他 | 硬阻断，返回通用 `BLOCK_TEXT` |
| `level 1/2` | **只记审计事件，不改行为**（降温文案尚未实现） |
| `level 0` | 正常走模型 |

**缺口**：词典是**人一条条补**的，漏的是**口语化、隐晦、非标准说法**。仓库待办里正有
"危机词新增口语变体继续进 V18"这一项 —— 说明这是已知的、靠人肉堆词的长期负担。

## 2. 目标

1. 在**规则之外**加一路 Jev 判定：`noul` 问题"这条消息是否表达自伤/自杀意愿（含口语、隐晦、玩笑式）"。
2. **只加召回，不替兜底**：词典命中 L3 的行为**一字不改**；Jev 只能**升级**，永远不能**放行**词典已命中的消息。
3. 命中的处理与词典同源：走同一个 `REFERRAL_TEXT` + 记同一种审计事件（`ruleId=jev:self_harm`），
   便于事后按 ruleId 统计"词典漏、Jev 补"的量。
4. 可开关（默认**关**）、阈值可配、失败**不改行为**（回到今天的样子）。

## 3. 非目标

- 不改词典、不改 L1/L2 语义、不动 `OutputGuardrail`。
- 不用 Jev 判断"非自伤类"的其它护栏等级（辱骂/注入等）——本轮只做有实测证据的那一类。
- 不做"Jev 说没事就放行词典命中"——**这是明确禁止的方向**（安全兜底不可被概率模型覆盖）。

## 4. 边界与取舍（必须先说清）

- **延迟**：这是**每一条用户消息的同步路径**。开启后每条多一次 Jev 调用（探针 p50 ≈0.3–0.9s）。
  这是"安全换延迟"，**默认关闭**，由产品决定；本轮会**实测出这个增量**再交给你判断。
- **误报代价**：Jev 判高风险 → 用户拿到转介文案而不是答案。故阈值默认取**高**（0.9），
  并用负向用例实测误报数。
- **失败语义**：Jev 不可达/超时 → **不加召回**（等同今天）。**必须写清楚**：这不是"安全回退"，
  而是"今天本来就漏，只是没变得更差"。
- 密钥只走环境变量（AGENTS.md §3）。
