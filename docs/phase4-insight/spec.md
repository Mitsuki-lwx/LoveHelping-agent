# spec.md — 对话洞察（非诊断，ADR-10 无风险）

> **问题**：用户在恋爱关系里不知道自己"说话有什么问题"——不知道自己总是用指责句式、不知道自己在回避冲突、不知道自己在重复同样的话术模式。传统的"诊断报告"有合规风险，且贴标签对用户不友好。
>
> **方案**：让用户上传/粘贴真实聊天记录，AI 分析其中的沟通模式，给出**观察性反馈**（不是诊断）。只说"你注意到什么"——"你提到冷战 3 次"、"你习惯用反问句"——不说"你有依恋障碍"。

---

## 核心设计原则

| 要做 | 不做 |
|------|------|
| 分析用户自己的聊天记录 | 分析他人记录（隐私红线） |
| 给出观察性反馈（"你提到冷战3次"） | 给出诊断结论（"你有回避型依恋"） |
| 识别沟通模式（"你习惯用反问句"） | 归因心理疾病（"你可能有焦虑症"） |
| 输出描述性数据（情绪词频、轮流长度） | 输出预测性结论（"你们一个月内会分手"） |

## 能力清单

| ID | 能力 | 说明 |
|----|------|------|
| CAP-1 | 粘贴聊天记录 | 用户粘贴对话文本（角色A: xxx\n角色B: xxx），AI 分析沟通模式 |
| CAP-2 | 上传聊天截图 | 用户上传截图 → VisionPort 提取文字 → 同 CAP-1 分析 |
| CAP-3 | 沟通模式分析 | 输出：情绪词频、轮流长度、反问/指责句式统计、冷战中断次数 |
| CAP-4 | 趋势对比 | 用户多次分析后，按时间对比变化（"最近绿篙词频率上升了"） |
| CAP-5 | 改善建议 | 给出可操作的建议（"你可以尝试用'我'开头代替'你'开头"） |
| CAP-6 | 数据隐私 | 分析结果仅用户可见，支持一键删除 |

## 输出格式

```
【对话洞察】（非专业诊断，仅供参考）

📊 基本统计
- 对话轮次：12 轮
- 双方轮流长度：用户平均 45 字 / 对方平均 23 字
- 中断/冷场：3 次

🔍 沟通模式
- 反问句式：6 次（"你从来不""你总是"）
- 指责句式：4 次（"都是你的错""你害我"）
- 表达感受：0 次
- 冷战/回避：2 次中断话题

💡 改善建议
- 尝试用"我感到..."代替"你总是..."
- 注意反问句的使用频率（占本轮对话 50%）
- 当感觉情绪上涌时，可以暂停 10 秒再回复

⚠️ 说明
以上分析基于您提供的对话片段，仅为观察性反馈，不做任何心理或关系诊断。
```

## Out of Scope

- 不做心理诊断/人格分类（"你有依恋障碍""你是焦虑型"）
- 不做关系预测（"你们会分手""他/她不爱你了"）
- 不做跨用户对比（"别人遇到这种情况...")
- 仅分析用户自己上传的聊天记录，不分析系统内的对话历史
