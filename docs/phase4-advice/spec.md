> **状态总览**：本套文档曾同时覆盖「话术三级建议（FR-CORE-01）」与「情绪刹车片（FR-CORE-02）」。

> 不再列入本 spec。本 spec 收敛为 **FR-CORE-01 话术三级建议** 的唯一事实源。
> 技术决策见 **ADR-18**；触发优先级生态内排序见下文。

---

## 问题

用户在恋爱关系里"不知道该怎么说话"（怎么回复、怎么哄、怎么道歉、怎么开口）。现有聊天只给一条笼统建议，用户没有可选的说话方案，也无从对比风险。

## 方案（一句话）

用户描述沟通场景 → 系统生成「安全牌 / 进击牌 / 后撤牌」三种话术，每种附「对方可能反应」，供用户选择并微调后再用。

## 能力清单（FR-CORE-01）

| ID | 能力 | 说明 |
|----|------|------|
| CAP-1 | 话术三级生成 | 识别"沟通建议请求"→ 生成三牌话术（🛡️安全/⚡进击/🌸后撤），每牌附"对方可能反应" |
| CAP-2 | 话术自定义 | 用户可在三牌基础上修改措辞、调整后再用（前端基于结构化输出渲染，单牌可编辑） |
| CAP-6a | 触发观测 | `advice.request`（话术请求计数）、`advice.activated`（实际生成三牌计数） |
| CAP-6b | 采纳观测 | `advice.tier.choice{tier}`（用户最终选用哪牌）——需前端回传，本期先落指标位、UI 标记采集点 |
| CAP-6c | 误伤观测 | `advice.misuse`（非话术请求却误触发的近似估算，暂以"未命中激活却触发"的日志近似） |

## 目标用户

所有 C 端恋爱顾问用户。不需要主动启用，系统在判定为沟通建议请求时自动介入。

## 触发优先级（生态内排序，与 ADR-18 第 2 条一致）

```
L3 硬阻断（PUA/操控/伤人/违法，ADR-6）   ── 最高，命中即拒绝，绝不生成三牌
        │
情绪刹车片（L2 深夜极端情绪，FR-CORE-02） ── 其次，先冷静提示，不叠加三牌
        │
话术三级（FR-CORE-01）                    ── 最后，正常生成三牌
```

## 设计骨架

```
用户输入
   │
   ▼
ChatEntry
   ├─ guardrailCheck（L3 阻断 → 情绪刹车片 → 记日志）      [已存在]
   ├─ adviceRequest = router.isAdviceRequest(message)      [新增]
   │     命中："怎么回复/说什么/如何开口/怎么哄/怎么道歉/怎么回/该怎么说…"
   │
   ├─ 无工具 & adviceRequest → ChatExecutor.execute(..., advice=true)
   │     · system prompt 三牌指令激活段（ADR-18：命中后追加指令强化结构）
   │     · 记录 advice.request / advice.activated
   │     · 输出侧把纯文本切片为结构化 advice 事件（增量，向后兼容）
   │
   └─ 其余 → 既有 ChatExecutor / AgentLoopExecutor 不变
```

## 结构化输出（CAP-2 前提）

- 话术请求时，SSE 增量新增 `advice` 事件：`{"type":"advice","tiers":[{"name":"安全牌","content":"…","reaction":"…"},…]}`。
- 事件为**增量**：非话术回复的纯文本行为完全不变（向后兼容）。
- 若 LLM 输出格式波动解析失败，降级为纯文本展示，不报错（前端容错，ADR-18 代价项）。

## 伦理红线（ADR-18 第 4 条，不因自动化放松）

- 三牌是**给用户的选择**，不是操控对方的工具——system prompt 明示"authentic 沟通，不控制对方"。
- 拿捏/操控/打压/PUA 类生成请求 → L3 拒绝，不生成三牌。
- 每牌只描述"对方可能反应"（可能性，不保证结果），不制造确定性操纵预期。
- 不生成引导撒谎、伪装身份、软性操控的内容。

## Out of Scope（按 ADR-18）

- **话术模板库（DB 结构化管理）** —— 远期演进，数据验证后再立项（ADR-16 触发条件）。
- 语气分析（从文本判定情绪状态）——更复杂 AI 能力，后续。
- 跨用户话术推荐——需数据积累。
- 话术发送后的结果跟踪闭环（用户选牌 → AI 是否"猜中"反应）——需长期留存与产品交互设计，本期不做。
