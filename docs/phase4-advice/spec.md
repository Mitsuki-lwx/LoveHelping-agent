# spec.md — 恋爱辅助核心：话术三级建议 + 情绪刹车片

> **问题**：用户在恋爱关系里"不知道怎么说话"和"情绪上头乱说话"——前者导致沟通质量低，后者导致关系恶化。现有聊天功能只给建议，不帮用户"练话术"和"控制冲动"。
>
> **方案**：话术三级建议让用户有三个安全的说话选择；情绪刹车片在深夜极端情绪时自动拦截冲动发言。

---

## 能力清单

| ID | 能力 | 说明 |
|----|------|------|
| CAP-1 | 话术三级生成 | 用户描述沟通场景 → 系统生成安全牌/进击牌/后撤牌三种话术，附对方可能反应 |
| CAP-2 | 话术自定义 | 用户可在三种话术基础上修改措辞，调整后再用 |
| CAP-3 | 情绪检测 | 深夜时段 + 极端情绪词 → 触发冷静提示（不阻断发送，提供"换个说法"选项） |
| CAP-4 | 转换句式 | 系统自动将用户的冲动表达转换为更温和的表达方式 |
| CAP-5 | 配置管理 | 极端词清单、深夜时段、触发行为均可通过 DB 规则配置（参照 guardrail_rule） |
| CAP-6 | 观测指标 | 触发率、采纳率（用户选择哪个牌）、误伤率（白天误触发）

## 目标用户

所有 C 端恋爱顾问用户——不需要主动使用，系统自动介入。话术三级在用户询问"怎么回复"时自动触发；情绪刹车片在深夜极端情绪时自动触发。

## 设计骨架

```
用户输入
    │
    ▼
ChatEntry（统一入口）
    │
    ├─ 情绪刹车片检查（CAP-3）→ 触发时返回冷静文案 + "换个说法"选项
    │     条件：深夜(23:00-06:00) + 极端情绪关键词
    │     动作：不阻断，返回特殊 SSE 事件 + 转换句式
    │
    ├─ 正常聊天流程 → ChatExecutor / AgentLoopExecutor
    │
    └─ 话术三级生成（CAP-1）→ 在系统提示词中注入指令
          条件：用户询问沟通建议（怎么回复/说什么/如何开口）
          动作：AI 自动生成三种牌 + 对方可能反应 + 应对预案
```

## 实现路径（待讨论）

- **话术三级**：系统提示词增强（已在 ChatExecutor.SYSTEM_PROMPT 中初步实现）→ 后续可升级为结构化模板 + LLM 混合
- **情绪刹车片**：扩展 ADR-6 护栏体系，新增 L2 级规则（`guardrail_rule` 表），深夜时段判定通过代码逻辑实现（不在 DB 规则里写时段，DB 只管关键词）

## 伦理红线

- 三种话术是**给用户的选择**，不是操控对方的工具
- 涉及"拿捏/操控/打压"的话术一律不生成（L3 护栏兜底）
- 情绪刹车片只提供"换个说法"选项，**绝不替用户做决定**（误伤时必须有"继续发送"出口）

## Out of Scope

- 话术模板库（数据库管理结构化话术模板）——后续演进
- 语气分析（从用户输入文本判断情绪状态）——更复杂的 AI 能力，后续
- 跨用户话术推荐（"别人遇到类似情况怎么回复的"）——需要数据积累
