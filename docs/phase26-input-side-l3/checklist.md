## ⛔ 未验证 / 已知限制（不掩盖）

1. **豁免词表必然有漏**：第三人称主语只列了 32 个常见项
   （"我一哥们儿""我发小""室友的女朋友" 这类**不**在表内 → 不会被豁免 → **仍拦**）。
   方向是偏严，符合设计，但**用户仍可能被无谓拒答**。
2. **离线样本是人工构造的、规模小、有偏**（21 + 7 + 6 条）→ 只作方向性参考。
3. **与 DB 是两份事实源**：`guardrail_offline_eval.py` 手抄规则，改一边必须改另一边
   （本相位两边逐字同步，但长期是漂移风险 —— ADR-56 已记同一问题）。
4. ⛔ **本轮暴露一个产品定位问题（已上报用户，未决）**：输入侧放开后，
   「我被诈骗了」「他割腕了」这类**完全不在关系域**的提问会拿到**长篇通用答案且不接回关系**
   （1011 / 1006 字，零关系维度）。这不是 bug，是 `SCOPE_ADJACENT_HELP` 的 (A) 类
   "先给 2-3 条建议再轻接回" 在长答场景下**没有兜住**。是否收紧 (A)、
   或把产品定位从「恋爱/关系」改成「情感」，**待用户拍板**。
