- ⛔ 但按纪律「重跑绿了不是归因」：**结论是"抖动"，不是"已修"** —— 该抖动仍挂在待办里。

## ⛔ 未验证 / 已知限制（不掩盖）

1. **样本量小**：每臂 21 条（7 问 × 3 轮），人工构造、有偏 → 只作方向性参考。
2. **"不展开清单"不可能穷尽**：只列了诈骗/法律/理财/纯诊疗四类。
   其它域外形态（如"帮我规划旅游路线"）**未测** → 行为未知。
3. **`REFER`/`RELM`/`URGM` 是关键词粗筛**，会在非目标文本上误触发
   （实测 G1 的"危机动作"标记 5/6→2/6 纯属噪声：失眠答案里出现"立即/马上"）。
   **判据结论一律以读原文为准。**
4. **与"情感"主题的关系**：本轮只把边界写成"情感/关系域（以爱情为核心）"，
   **没有**把产品定位改成情感；将来扩到亲情/友情/自我需换 KB + 改边界清单。
5. ⛔ **ADR-59 记的那条"定位问题"仍未关闭**：本轮只是把**域外事务**收住了；
   域内是否还过宽（例如"和朋友闹别扭"这类非恋爱关系）**未评估**。
