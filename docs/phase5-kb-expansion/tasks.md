# tasks.md — Phase 5 知识库扩充（86 → 131 篇）

> 目标：把 knowledge base 从 86 篇扩到 ~131 篇（+45），补齐**真实用户高频、当前完全空白**的场景域，使覆盖达到行业"中型实用库"（50–500 篇）中段，并守住既有评测基线（Recall ≥ 0.95 / MRR ≥ 0.85）。
>
> 依据：`docs/knowledge-base-sources.md`（授权合规链）、`docs/09-测试策略.md` §7、AGENTS.md §1/§2。

---

## 0. 背景与触发

- 现状（2026-09-11）：`src/main/resources/document/` 共 **86 篇 / ~9.1 万字**，切块 ~251，45 例评测 **Recall 0.98 / MRR 0.88**。
- 行业基准（Chan et al. 2025, Mindline.sg；Wysa 公开数据）：心理健康 RAG 在混合检索+重排体系下，**162 篇 ≈ 95% 最优召回，288 篇 ≈ 99%**；领域实践普遍认为 50–500 篇为"中型实用"区间。
- 结论：86 篇已达 MVP 上限，但存在**成体系的主题空洞**（见 §1），补齐到 ~131 篇可显著提升长尾覆盖，且仍处边际收益递减前的合理区间。
