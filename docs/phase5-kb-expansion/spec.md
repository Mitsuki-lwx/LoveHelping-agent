# spec.md — Phase 5 知识库扩充：内容规格

> 承接 `tasks.md`。本文件定义**每篇文档的主题、目标字数、来源与许可、写作规范**，以及入库与评测口径。

---

## 1. 写作规范（与现有 86 篇保持一致）

- **格式**：Markdown，一级标题 `# 中文标题`，正文 800–1400 字；用 `##` 分 2–5 个小节；关键结论加粗；适当用列表/短句。
- **文风**：中文、口语可读、不说教；先共情后方法；给可执行动作（话术示例、步骤清单）。
- **边界声明**：涉及法律/医疗/心理危机的文章，文末必须有"本文是常识整理，不构成法律/医疗意见；如有需要请寻求专业帮助"类声明。
- **来源标注**：文件名为「中文标题_english-slug.md」；来源与许可**统一登记**在 `docs/knowledge-base-sources.md`（避免正文冗余）。现有 86 篇亦以此为口径。
- **不得**照搬受版权保护原文；一律采用「公开理论 + 自撰改写」或「立法文件」模式。
- **危机类文档（G4）**：必须给出**全国统一心理援助热线 12356**（国家卫健委 2024-12 设置，2025-05-01 全国接通，24h 免费，来源 gov.cn 国卫医政函〔2024〕259 号），以及"紧急危险拨 110/120"。

## 5. 入库与评测口径

- **入库**：沿用启动时增量同步（按 doc_hash）或调用 `/rag/reindex`；新增 45 篇 → 预期总量 ~131 篇、切块数由 251 → ~380–420。
- **评测**：`scripts/retrieval_eval.py`（45 例 ground-truth）复测；**通过线 Recall ≥ 0.95 / MRR ≥ 0.85**（不低于扩充前基线一个百分点以上为不合格）。
- **抽样**：新主题各抽 1 例（同性伴侣/不孕不育/自杀风险/网恋骗局/婚前协议）人工核对召回来源相关。
