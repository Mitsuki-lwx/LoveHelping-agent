# 01 · 产品定位与需求

## 1. 一句话定位

面向 C 端用户的 **AI 恋爱军师**：基于对话的恋爱关系咨询、约会规划与沟通能力训练，附带 B 端（恋爱咨询机构）多租户能力。

## 3. 非目标（明确不做）

- **不做**专业心理治疗/精神科诊断。检测到抑郁、自伤信号时的动作是**转介**（推送援助资源），不是治疗（见 07 §5）。
- **不做**教用户操控他人的内容（PUA 类请求硬阻断，见 06 §4）。
- **不做**通用文件解析（PDF/Word 等）：图片是唯一非文本输入（ADR-11）。
- **不做**实时语音/视频（近期）；文本 + 图片 + SSE 流式为交互形态。
- **不做**通用聊天机器人。系统 Prompt、RAG 语料、工具集全部围绕亲密关系领域。
- **立项前提式不做**：人格诊断/健康度仪表盘等"诊断三件套"与用户成长等级，在**科学性与合规边界未确认（ADR-10）、真实数据未积累前不做**（见 11 §5.2 与 11 §6 远期附录）。

## 4. 功能需求分级

### P0（生产上线门槛，缺一不可）
1. 流式聊天（含 RAG）与 Agent 任务两条管道稳定可用。
2. 认证（JWT）+ 用户级数据归属校验收口（跨用户越权审计，ADR-13 后租户工程冻结）。
3. 内容护栏：输入/输出双向（已有 `harness/governance`，需强化规则与误伤监控）。
4. LLM 降级链（GoPlan 主 → DeepSeek 备 → 诚实报错 E5000）。
5. 可观测性三支柱 + Token 成本核算。
6. 密钥治理：`mcp-servers.json` 中硬编码的 API Key 必须移除（见 07 §2）。

### P1（上线后一个迭代内）
- 会话/消息持久化改造（软删除、审计字段）— ✅ 已实现（message 表，Phase 2）。
- Agent 任务落库 + 重启补偿 — ✅ 已实现（agent_task + 心跳补偿，Phase 2，ADR-3）。
- Prompt 版本管理与 Golden Set 回归（prompt_version 已随消息落库；Golden Set 为 Phase 3 规划）。
- 图片多模态：聊天截图分析 — ✅ 已实现（Phase 2，ADR-11）。
- **记忆系统阶段 2**：跨会话记忆（会话摘要 + 用户可编辑的事实记忆）— ✅ 已实现（Phase 2，ADR-14）。

### P2（差异化，按数据决策是否投入）
- 话术三级建议（⏸ 待立项，SRS FR-CORE-01）。
- 情绪刹车片（⏸ 待立项，SRS FR-CORE-02）。
- B 端租户运营功能（配额计费、审核后台；ADR-13 冻结，不在 SRS 范围）。

### 远期附录（按数据决策立项，见 11 §6）
- 认知诊断、人格诊断报告、关系健康度仪表盘（诊断三件套，前置 ADR-10 定稿，科学合规未证前不做）。
- 沙盘模拟（前置 ADR-9 + ADR-12 定稿）。
- 用户成长等级、个性化推荐（预留）。
- 关系档案 `relationship_profile`（随沙盘/诊断立项，ADR-14 阶段 3）。

## 5. 关键非功能需求（NFR）

| 维度 | 目标 | 度量方式 |
| --- | --- | --- |
| 聊天延迟 | P95 < 3s（首 token < 1.5s） | Micrometer Timer `chat.latency` |
| 可用性 | 99.5%（月级），LLM 厂商故障不放大为全站故障 | 降级触发率 < 5% 请求 |
| 并发 | 单实例 200 并发会话（SSE 长连接） | 压测（见 09 §5） |
| 数据 | 用户私信加密存储、删除权级联到向量 | 审计清单（07） |
| 成本 | 每 DAU Token 成本可核算到租户/会话 | `llm.token.usage` 指标 |
