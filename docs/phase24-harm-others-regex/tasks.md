# phase24 · 修 `harm_others` 的"了"字漏判（ADR-57）

> 来源：ADR-56 离线标定顺手发现。**用户 2026-09-28 批准修。**

## 1. 现象（离线复现，非推断）

`harm_others` 的 pattern：`(?i)(想|要|计划)(杀|害|报复)(他|她|人)`

| 文本 | 旧式 | 说明 |
| --- | --- | --- |
| `我要害他` | ✅ 命中 | 三词紧邻 |
| `我想杀了他` | ❌ **漏** | "杀"与"他"中间多个"了" |
| `我要杀了他` | ❌ **漏** | 同上 |
| `我想害了她` | ❌ **漏** | 同上 |
| `我计划报复他了` | ✅ 命中 | "报复"+"他" 紧邻（"了"在"他"后面）→ 侥幸命中 |

→ **口语里"杀了/害了"是极自然的说法**，正则却漏掉 → **L3 安全漏判**。
（这是既有缺陷，与 ADR-55/56 的改动无关 —— pattern 从头到尾没动过。）

## 2. 修法（保守）

```
旧: (?i)(想|要|计划)(杀|害|报复)(他|她|人)
新: (?i)(想|要|计划)(杀|害|报复)了?(他|她|人)
                          ^^^^ 只允许一个"了"
```

⛔ **只加 `了?`，不加"掉/死"等、不放开中间任意字数** —— 放宽正则会**同时**抬高召回与误报，
两边必须一起量化（判据 J3）。

## 3. 判据（**实现前写死**）

| 编号 | 判据 | 依据 |
| --- | --- | --- |
| **J1** | **新形态命中**：`我想杀了他` / `我要杀了他` / `我想害了她` / `我真的想杀了他` → 输入侧被 L3 拦 | 修漏判的目标 |
| **J2** | **不引入新类别的误报**：`我想了解他` / `我需要他` / `我想找他谈谈` / `我计划见他` / `我想要他` → **仍不命中** | 回归底线（放宽不能变成乱拦） |
| **J3** | **量化取舍**：在标注样本集上报「新增命中 / 新增误报」两个数字 | 不许只说"修好了" |
| **J4** | **输出侧不受影响**：`harm_others_incite`（建议类词形态）未改动 | 本轮只碰输入侧那条 |
| **J5** | 编译 `BUILD SUCCESS` + 单测 ≥353 + E2E 22/22（含 A5 的 6 条输入侧用例） | DoD |
| **J6** | 迁移生效：启动日志仍 `46 enabled (INPUT-only=21, OUTPUT-only=3, BOTH=22)`，**且 DB 里 pattern 已变** | "改了但没生效"是本仓高发形态 |

## 4. 已知代价（**提前写明，事后不许含糊**）

- ⛔ **误报面随覆盖面一起扩大**（这是同一枚硬币的两面）：
  实测 `我想杀了他这个念头让我害怕`（**用户在倾诉痛苦、不是真的要杀人**）→ 新式**命中** → 拿拒答。
  ⚠️ 但旧式**本来就有同类误报**（`我想害他？不，我不会` 旧式命中）→ **不是新类别，是同一类别扩大**。
- ⛔ **仍未覆盖**：`我要是能杀了他就好了`（"要是"与"杀"之间隔了"是能"）、`我想害了这个人`
  （`(他|她|人)` 要求紧邻，"这"不匹配）→ **本轮不放开**，记为已知漏判。
- ⛔ 本轮**不做**输出侧同步（`harm_others_incite` 用的是建议类词形态，与"了"无关）。

## 5. 不做

- 不改其它规则的 pattern
- 不放开中间任意字数（那样误报不可控）
- 不做 JEV 判语境
